# 三大错位诊断透镜 (Three Strategic Misalignments)

## 概述

本文档定义 IOM 诊断的**顶层推理透镜**，将隐性假设显性化为三层推理链：
**错位 (Misalignment) → 假设 (Hypothesis) → 证据 (Evidence)**

该透镜用于 `frame-iom-problem` Skill 的痛点映射阶段，确保所有 H1-H8 假设均溯源至战略层错位。

---

## 错位一：战略 - 执行断层 (Strategy-Execution Gap)

**定义**：公司级战略目标（如"高端化"、"全球化"）未能转化为制造系统的可执行参数，导致"大脑想往东，四肢往西走"。

### 推理链

```
错位 1 ⇒ H1, H2, H3
```

| 假设 ID | 假设描述 | 典型证据模式 |
|---------|----------|--------------|
| **H1** | 战略意图未解码为工艺/质量参数 | - 战略规划文档无制造章节<br>- 工艺卡片无产品族差异化参数<br>- 质量目标与战略 KPI 无追溯关系 |
| **H2** | 产品平台化不足导致制造复杂度爆炸 | - SKU 数量/产品线数量比 > 行业标杆 2x<br>- 通用件占比 < 40%<br>- 换型时间占总工时 > 15% |
| **H3** | 需求预测与产能规划脱节 | - 预测准确率 < 60%<br>- 紧急插单率 > 25%<br>- 产能利用率波动标准差 > 30% |

### 诊断问题清单

1. 最近一次战略规划会议是否包含制造 VP 的正式输入？
2. 是否有从战略主题到车间 OEE 的完整指标分解树？
3. 新产品导入 (NPI) 流程中，制造可行性评审的否决权权重是多少？

---

## 错位二：价值流 - 职能墙冲突 (Value Stream vs. Functional Silos)

**定义**：端到端价值流交付要求跨职能协同，但组织 KPI、预算、汇报线仍以职能部门为中心，导致"局部最优、全局次优"。

### 推理链

```
错位 2 ⇒ H4, H5
```

| 假设 ID | 假设描述 | 典型证据模式 |
|---------|----------|--------------|
| **H4** | 职能 KPI 与价值流交付目标冲突 | - 采购 KPI 为单价降低，导致批量过大/库存高企<br>- 生产 KPI 为设备利用率，导致过量生产<br>- 质量 KPI 为一次合格率，导致过度检验/瓶颈阻塞 |
| **H5** | 价值流 Owner 缺位或无实权 | - 无端到端流程 Owner 岗位<br>- 价值流改进项目需 5+ 部门审批<br>- 跨部门会议决策执行率 < 50% |

### 诊断问题清单

1. 是否存在对端到端交付周期 (OTD) 负责的单一角色？其预算权限是多少？
2. 各部门 KPI 中，跨职能协同指标的权重占比是多少？
3. 过去 12 个月，有多少个跨部门改进项目因部门利益冲突而被搁置？

---

## 错位三：数字化 - 业务场景脱钩 (Digital-Business Decoupling)

**定义**：数字化投资（MES/APS/IIoT）未锚定具体业务痛点，沦为"为数字化而数字化"，导致系统上线后业务价值无法兑现。

### 推理链

```
错位 3 ⇒ H7, H8
```

| 假设 ID | 假设描述 | 典型证据模式 |
|---------|----------|--------------|
| **H7** | 数字化项目 ROI 测算缺乏业务基线 | - 项目立项书无量化业务目标（如 WIP-30%）<br>- 系统上线后无业务效果追踪机制<br>- IT 预算与业务改善 KPI 无绑定 |
| **H8** | 数据治理缺失导致"垃圾进垃圾出" | - 关键主数据（BOM/工艺路线）准确率 < 95%<br>- 系统间数据一致性 < 90%<br>- 一线员工手工台账与系统并行率 > 50% |

### 诊断问题清单

1. 过去 3 年数字化项目中，有多少个在验收时提供了业务价值达成报告？
2. 业务部门在数字化项目选型中的投票权权重是多少？
3. 数据质量 KPI 是否纳入相关部门负责人的年度绩效考核？

## 使用方法

### 在 `painpoint_mapper.py` 中的调用逻辑

```python
# 伪代码示例
def map_painpoints_to_hypotheses(painpoints: list) -> dict:
    # 步骤 1: 识别主导错位
    dominant_misalignment = detect_misalignment(painpoints)  # 返回 1/2/3
    
    # 步骤 2: 根据错位锁定假设子集
    if dominant_misalignment == 1:
        candidate_hypotheses = ["H1", "H2", "H3"]
    elif dominant_misalignment == 2:
        candidate_hypotheses = ["H4", "H5"]
    else:  # misalignment == 3
        candidate_hypotheses = ["H7", "H8"]
    
    # 步骤 3: 基于证据强度排序
    ranked_hypotheses = rank_by_evidence(candidate_hypotheses, painpoints)
    
    return {"misalignment": dominant_misalignment, 
            "hypotheses": ranked_hypotheses}
```
